# RenalCare
RenalCare adalah aplikasi web pemantau kesehatan ginjal untuk pasien CKD dewasa. Dilengkapi pencatatan hasil lab, kalkulator eGFR &amp; stage G/A otomatis, grafik tren, jurnal tekanan darah, pengingat kontrol, dan edukasi terkurasi berbasis pedoman KDIGO agar pasien siap berdiskusi dengan dokter
